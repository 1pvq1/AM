# Refactor Project Structure under commonMain

This plan outlines the redesign of the `commonMain` folder structure to improve organization, maintainability, and scalability. The new structure follows a layered architecture with clear separation between data, domain, and presentation layers.

## Proposed Structure

The code will be reorganized into the following package hierarchy under `com.example.androidmaiden`:

- `data`: Data layer handling local and remote data sources.
    - `local`: SQLite database (Room), DataStore, and entities.
    - `network`: API interfaces and network services (e.g., Gemini API).
    - `repository`: Repository implementations.
- `di`: Dependency Injection modules.
- `domain`: Business logic and models.
    - `model`: Data classes and domain models.
- `presentation`: UI and ViewModels.
    - `ui`: Compose UI components.
        - `theme`: App themes and styling.
        - `components`: Generic and reusable UI components.
        - `features`: Feature-specific UI components (e.g., character, tasks).
        - `screens`: Top-level screen composables.
    - `viewmodel`: ViewModels.
- `util`: Utility classes and functions.
- `platform`: Platform-specific `expect`/`actual` declarations (e.g., permissions, string resources).

## Proposed Changes

### [Data Layer]

Move data-related files to `data.local`, `data.network`, and `data.repository`.

- `DBEntity.kt`, `AppDatabase.kt`, `FileMetadataDao.kt`, `DataStore.kt` -> `data/local`
- `GeminiApi.kt`, `LlmProvider.kt`, `LlmService.kt`, `LlmServiceImpl.kt` -> `data/network`
- `*Repository.kt` -> `data/repository`

### [Domain Layer]

Move models to `domain.model`.

- `model/*` -> `domain/model`

### [Presentation Layer]

Move UI and ViewModels to `presentation`.

- `viewModels/*` -> `presentation/viewmodel`
- `ui/theme/*` -> `presentation/ui/theme`
- `ui/*.kt` (generic) -> `presentation/ui/components`
- `views/SectionSeperator.kt` -> `presentation/ui/components`
- `views/character/*`, `views/panel/*`, `views/fileSys/*`, `views/others/*`, `views/Chat.kt` -> `presentation/ui/features`
- `screens/*` -> `presentation/ui/screens`

### [Core/Platform]

- `Res/StringResources.kt` -> `platform/StringResources.kt`
- `mods/*` -> `platform/*`
- `utils/*` -> `util/*` (just renaming `utils` to `util`)

### [Root]

- `App.kt`, `AppSettings.kt` remain at the root of `com.example.androidmaiden`.
